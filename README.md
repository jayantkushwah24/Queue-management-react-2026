# Queue Management System

A simple and responsive Queue Management System built with React.  
This application allows you to add customers to a queue, track their service type, update their status, and remove them when completed.

---

## Features

- Add customers to the queue with service type
- Automatic status lifecycle:
  - `waiting` → `in-progress` → `completed`
- Update customer status with a single action
- Remove customers from the queue
- Clear empty-state handling
- Responsive layout (desktop and mobile)
- Reusable, controlled form components
- Clean and minimal UI (no CSS frameworks)

---

## Tech Stack

- **React** (Functional Components + Hooks)
- **CSS** (Vanilla CSS, no Tailwind / Bootstrap)
- **react-icons** (for UI icons)
